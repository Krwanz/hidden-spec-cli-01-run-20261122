mend is one command-line patch tool for every AI edit format. It reads a unified diff, SEARCH/REPLACE blocks, a V4A patch, or JSON text-editor tool calls, finds each edit's lines at the first of three matching tiers (exact, trailing whitespace, leading and trailing whitespace), and writes every change or none. Node 22, standard library only, deterministic.

## Run it

```sh
node main.ts [options] [PATCH]
```

`SPEC.md` is the whole contract: the four formats, the matching tiers, the output lines and the exit codes. `check.ts` runs the 100 public practice checks against `main.ts`.
